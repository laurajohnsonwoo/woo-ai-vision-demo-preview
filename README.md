# WooCommerce AI current and Vision previews

This repository hosts the compiled attendee-facing web app for Laura Johnson's exploratory WooCommerce AI product previews. It combines four representative current-state beta stories with a guided, aspirational creator-campaign Vision flow.

**[Open the preview](https://laurajohnsonwoo.github.io/woo-ai-vision-demo-preview/)**

## Use on an iPad

The iPad must be online for the first visit.

1. Open the preview link in Safari.
2. Wait for the experience to load completely.
3. Choose **Share**, then **Add to Home Screen**.
4. Open the new Home Screen app once while still online.
5. Test it in Airplane Mode before relying on offline use.

The installed web app can reopen offline after its application assets have been cached, although iPadOS may eventually clear website data.

## Repository purpose

This public repository contains compiled deployment output only. It is not the editable application source, an official WooCommerce product repository, a roadmap, or a canonical product specification.

The editable source, implementation guidance, and product-truth documentation are maintained internally at [Automattic/woo-ai-vision-demo](https://github.a8c.com/Automattic/woo-ai-vision-demo).
